Tâche : Consulter la météo d'un lieu habituel avant de s'y rendre.

Début : la personne ouvre l'application.

Fin réussie : la personne a vu la météo du lieu où elle va se rendre et sait comment s'habiller / si elle doit prendre un parapluie.

Chemin

Jean ouvre l'app → écran d'accueil avec la liste de ses lieux habituels
Il voit "Yverdon" dans la liste, avec un aperçu météo rapide (icône + température)
Il tape sur "Yverdon" pour avoir le détail
L'écran affiche température, vent, nuages, et l'heure prévue de son trajet
Jean ferme l'app, satisfait

Variante d'échec (optionnel)
Si ça rate (pas de connexion / API indisponible), l'écran dit : "Impossible de récupérer la météo pour le moment. Réessaie dans quelques instants."
